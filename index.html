TENTANG FADHIL GAME

Fadhil GAME adalah platform hiburan arcade modern berbasis web yang di-hosting langsung di GitHub Pages dan terhubung ke backend serverless Google Apps Script + Google Sheets.

⚡ HTML5 Canvas 60 FPS 🎵 Procedural Synthwave Web Audio 🌐 Hosted on GitHub Pages ☁ Google Apps Script REST API 📊 Google Sheets High-Score Database 📳 Haptic Mobile Feedback
