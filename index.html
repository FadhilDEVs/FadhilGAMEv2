TENTANG FADHIL GAME

Fadhil GAME adalah platform hiburan arcade modern berbasis web yang di-hosting langsung di GitHub Pages dan terhubung ke backend serverless Google Apps Script + Google Sheets.

⚡ HTML5 Canvas 60 FPS 🔊 Web Audio API Synthesizer 🌐 Hosted on GitHub Pages ☁ Google Apps Script REST API 📊 Google Sheets High-Score Database
🕹️

Misi Platform

Menghadirkan arcade instan tanpa instalasi yang kompetitif dan responsif di berbagai perangkat.

🤖

Robot Stop-Motion

Maskot navbar bergerak 10 FPS diskret untuk menghadirkan nuansa animasi puppet stop-motion yang khas.

🔒

Penyimpanan Terintegrasi

Semua skor dan akun pemain tersimpan rapi dan otomatis ke spreadsheet Google Drive kamu.
